## Overview

Mass Effect Modder (MEM) is a cross-platform tool for installing and creating high-resolution texture mods for Mass Effect 1, 2, 3, and the Legendary Edition. Using the efficient MEM package format with GPU-compressed BC7 textures and LOD fixing, it allows texture artists to distribute single-file mods that install cleanly into any edition of the trilogy on Windows, Linux, and macOS.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Mass Effect Modder** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full Trilogy Support** | Covers Mass Effect 1, 2, 3, and all Legendary Edition variants |
| **GPU-Compressed Textures** | BC7 texture compression with automatic LOD bias correction |
| **Cross-Platform** | Native tool builds for Windows, Linux, and macOS |
| **MEM Package Format** | Single-file MEM packages for clean mod distribution and installation |
